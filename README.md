# Conake Browser downloads

Download **v0.1.12** to install Conake Browser. No source checkout or Node.js is needed.

![Conake Browser logo](conake-browser-logo.svg)

**New in this version:** original Anime Eclipse artwork, a new serpent-C logo and app icon, refreshed tabs and built-in pages, and three appearance themes: Crimson Eclipse, Violet Pulse and Midnight. Settings can hide the artwork or reduce motion. Copy/paste menus, community links, the blank-tab fix and encrypted accounts are included.

On first launch, create a local account with a password of at least 12 characters. Sign in to unlock your encrypted bookmarks, history, settings, and API keys. Click **Lock** to sign out. Accounts stay on this computer; there is no cloud sync or password recovery. Website sessions end on sign-out or restart. Downloaded files remain ordinary files outside the encrypted profile.

This repository contains download pages and installer distribution tooling. Application source is maintained privately. GitHub's **Code → Download ZIP** and automatically generated **Source code** archives contain these download-page files, not the browser installer. Use an installer above.

The import workflow transfers installers from a release that is still publicly accessible. After the development repository becomes private, a maintainer must upload the six release assets here manually and update the version links. Do not publish application source archives.

## Copy and paste

Right-click or use a two-finger trackpad click for text, link and image options. Click **Edit ▾**, beside Lock, to open editing options with a normal left click. Use **Ctrl+C**, **Ctrl+X**, **Ctrl+V** and **Ctrl+A** for copy, cut, paste and select all (Command on Mac).
