02/Release notes

What is new in 0.3.0.

Interface work in the 0.3.0 desktop build. The Android preview is still 0.2.0.

  1. 01

    A Chromium shell, not a skin

    40 px tab strip, single-row toolbar, 8 px omnibox and Chrome's tab shapes. The frame is now the default interface.

  2. 02

    Chrome dark and light

    Both palettes ship with this build, with instant switching from the profile menu or a match to your system theme.

  3. 03

    Menus that stay on top

    The three-dot and profile menus are drawn in their own overlay window, so a page can no longer cover them. Arrow keys, Enter and Escape work.

  4. 04

    The Conake skin is optional

    The studio look, glass and rainbow tab accents are still there, one click away in the profile menu.

  5. 05

    Startup fixes

    Three startup bugs are fixed in this release.
